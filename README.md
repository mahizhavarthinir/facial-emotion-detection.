
# Facial Emotion Detection Using Deep Learning

## Project Overview

Facial Emotion Detection is a deep learning project that identifies human facial emotions from an uploaded image. It uses a Convolutional Neural Network (CNN) to classify facial expressions into seven emotion categories.

The system detects a face in the uploaded image, preprocesses it, and predicts the emotion with corresponding probability scores.

## Features

- Upload an image for facial emotion detection.
- Detect faces in the uploaded image.
- Preprocess facial images into grayscale format and resize them to 48 × 48 pixels.
- Predict seven emotion categories.
- Display emotion probability scores.
- Visualize the predicted emotion.

## Emotion Categories

1. Angry
2. Contempt
3. Disgust
4. Fear
5. Happy
6. Sad
7. Surprise

## Technologies Used

- Python
- TensorFlow / Keras
- Convolutional Neural Network (CNN)
- MediaPipe
- NumPy
- Matplotlib
- Google Colab

## Dataset

The project uses the CK+ (Extended Cohn-Kanade) facial expression dataset for training and evaluating the emotion classification model.

## How It Works

1. Upload a facial image.
2. Detect the face using MediaPipe.
3. Convert the detected face to grayscale.
4. Resize the image to 48 × 48 pixels.
5. Pass the processed image to the trained CNN model.
6. Display the predicted emotion and probability scores.

## How to Run

1. Open the notebook in Google Colab.
2. Run the notebook cells in order.
3. Upload a facial image when prompted.
4. View the predicted emotion and probability scores.

## Project Platform

Developed and executed using Google Colab.
